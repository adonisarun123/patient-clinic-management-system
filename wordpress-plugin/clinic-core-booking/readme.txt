Embeds the Clinic Core appointment booking widget on a clinic's WordPress site.

== Installation ==
1. Zip the clinic-core-booking folder and upload it under Plugins → Add New → Upload, then activate.
2. Settings → Clinic Core Booking: enter the Clinic Core URL, clinic slug and publishable key.
3. Add the [clinic_booking] shortcode to the "Book appointment" page.

== Privacy ==
The plugin stores no patient data in WordPress. The booking form runs in an isolated iframe served by Clinic Core.
